# mw-spec-goal-command

## 系统行为变化

pi PM 窗口新增 `/mw-spec-goal`。窗口当前模型根据现行规格和项目目标拟两三句话，用户在编辑器中修改并确认后，宿主把文字写入当前 key 的 `spec.md`。下一轮请求沿现有方式读取该段。已有的目标继续沿用。

提交时重读权威认领和现行规格。取消、模型失败、已存在目标、认领变化或规格变化均不写入。旧规格的原文字节和换行保留。

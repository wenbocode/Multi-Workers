# mw-dp-receipt-repair-feedback

## 系统行为变化

窗口回执失败会给责任人一个 `next`。无任务裁决附带任务观察时，PM 得到具体字段和修正动作，用同一裁决、阶段和事件重交。其他输入错误指出待修正字段。绑定失效时先核实绑定，写入结果不确定时先按原事件查账。成功回执沿用现有格式。

## 验收

实现者自验 83 项通过，覆盖回执拒绝、原事件单次修正写入、零新增 DP 请求和不确定写入对账。完整 `npm run check` 在隔离副本通过。扩展回归的一项多 active key 测试在修改前后均于首次 ask 失败。[定向验收](evidence/codex-pm/self/1795486948449172500-bt0dtl3m/result.json)

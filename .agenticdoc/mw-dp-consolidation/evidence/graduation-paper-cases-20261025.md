## 八入口的业务归属（目标，不是当前工具schema）

| 入口 | 判断对象/选项 | 不能代替什么 |
|---|---|---|
| dp-w-type | PM准备任务派发类型；coding/research/review/vision | 图像能力/角色/写面硬门，或其他框架类型的存废决定 |
| dp-pm-steer | PM任务编排；narrow/split/direct-exec/escalate | 目标取消/验收缩减，PM无上下文理由的兜底接管 |
| dp-w-check-task | Worker本次可达性；继续/终止真实结论/继续补证 | 同步等PM指令，key取消或目标完成 |
| dp-QG | 正式质量判断；pass/fix/reopen | key签收、stage审批、改契约权限或已派返工 |
| dp-gate-approve | 某具体gate审批；approve/steer/need_fix/reject | 已执行、后继DP已调用、扩预算授权或其他gate审批 |
| dp-sign-key | key交付签收；finalize/continue/user-confirm | phase已done或stage关闭、其他必需硬门 |
| dp-auto | PM准备动态候选、决策选一项并说明依据 | 未准备新方案、固定DP必需判断、已执行/新权限 |
| dp-route | 按主体/对象/问题选七个业务入口 | 业务答案、角色资格或固定节点额外强制路由 |

依据：spec.md:25–31、:60–64、:67–69。精确角色矩阵、材料/技术ID和consumer留设计；此表只总结已确认责任，不加新运行角色检查。

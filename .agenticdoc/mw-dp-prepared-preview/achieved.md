# mw-dp-prepared-preview

## 系统行为变化

窗口通过宿主代码准备材料。可选 preview 读取授权范围内的证据并生成正式请求使用的材料，返回草稿引用、快照和诊断。首次直接提交有效材料即可请求裁决。材料拒绝后，PM 或 Worker 可沿用同一引用，仅提交修正标识和值。

宿主按字段比较草稿。不同字段的修正可交错到达，重复写入同一值可重放。同一字段被改成另一个值，或引用文件在准备之后变化时，宿主返回复核提示。正式发送前复查当前事项约束和材料快照。草稿绑定原事项与实际所有者。

## 遗留

以上为 Codex PM 实现者自验。运行中的三个项目窗口仍使用各自的安装版本，跨项目实窗验收归 mw-dp-window-acceptance。工具参数须能进入 ask_decision；草稿保存适用于宿主收到且可安全持久化的材料。

### 2.6 首次 smoke 暴露的缺陷（本轮修复）

第一轮 smoke 使用同一份 BOM 前缀 `dispatch.yml`：

```
工具返回： (1) ... model: route default (no dispatch.yml review default)   ← TS 侧没读到配置
Python：  load_dispatch_config(...) → {'models': {'review': 'timi/gpt-5.6-sol'}}  ← PyYAML 读到了
launcher.log: [launcher] smoke-ok: model=timi/gpt-5.6-sol source=config:review    ← 解析链按配置生效
```

根因：`readRoleModel` 用 `/^models:\s*$/` 匹配首行，BOM（U+FEFF）使该行失配 → 配置被视作空，
override 门与 id 校验**静默失效**（fail-open）。修复：读取后剥离首个 U+FEFF（`dispatch-models.ts`），
并补双侧测试（TS `VC-013`；Python `test_bom_prefixed_file_reads_like_the_ts_reader`）。
修复后同一份 BOM 文件触发 reason 门（见 2.5 第 1 条返回）。

## 上下文

三个已接线 dp 的 state 键名今天在 TS 里**硬编码**：dp1 `pm/ui-bridge.ts:446`、dp2 `pm/pm-orchestrator.ts:2130`、dp3 `worker/worker-mode.ts:4993 buildDp3State`。权威定义在 `decision_points.py` 的 `REQUIRED_STATE_FIELDS`（dp1 13 条 / dp2 14 条 / dp3 13 条）与 `STATE_FIELD_DESCRIPTIONS`，已导出到 `packages/multi-workers/decide_registry.json` 的 `required_state_fields`（`{name,type,description}`）。W4 的 `mw decide dp verify` 已能按它造最小 state。用户要求：PM/worker 必须**按配置**生成字段内容到 state，因此 TS 不能再手写第二份字段清单。现成范式：`packages/ai/src/models.generated.ts` 由脚本生成 + 漂移检查。

## 要求

1) 生成器 `packages/multi-workers/scripts/gen_decide_registry_ts.py`：读 `decision_points.registry_snapshot()`，写出 `packages/coding-agent/src/extensions/agent-team-loop/shared/decide-registry.generated.ts`，内容为 `export const DECIDE_REGISTRY: Record<string, { questionsVersion: string; requiredStateFields: { name: string; type: string }[]; contextSlots: string[] }>`（按 dp 排序、稳定缩进、头部 `// @generated by packages/multi-workers/scripts/gen_decide_registry_ts.py — do not edit`），`contextSlots` 取该 dp 的上下文槽位白名单（W6 的 `CONTEXT_SLOTS` 定义；dp1 只有 task_excerpt、dp2 change_summary+artifact_status、dp3 change_summary+candidate_snippets）。
2) 新建 `packages/multi-workers/decision_context.py`：`CONTEXT_SLOTS`（slot → {type, max_chars|max_items, item_max_chars, producers}）、`truncate_slot`（头 60% + 尾 40% + `…truncated N chars…`）、`fit_context`（总长 ≤ 4000，按 error > candidate > change > task > artifact 砍）、`validate_context`（未知槽位/缺 `source`/超限 → issue 列表，不抛）、`redact_context`（复用 `decision._redact`）。
3) TS 生产者改为**从 `DECIDE_REGISTRY` 取字段清单**并在构造后自检：`assertStateMatchesRegistry(dpId, state)`（缺/多都 throw，消息带缺失与多余键名）；dp3 额外填 `context.candidate_snippets`（每个候选命中行原文前 200 字符 + `source`）与 `context.change_summary`；dp2 填 `context.artifact_status`（`[{path,exists,bytes}]` ≤24）与 `change_summary`；dp1 填 `context.task_excerpt`（派发卡 `## 上下文`/`## 要求` 摘录 ≤1200）。
4) `decision_points.py`：`_fit_state` 先跑 `fit_context` 再丢可选字段，context 计入 2000 B；`REQUIRED_STATE_FIELDS` 不新增 context 路径。
5) 测试：`test_decision_context.py`（≥14 例：截断标记、砍序、未知槽、缺 source、脱敏、进 digest、缺失不影响 decide、计入 2000 B）；`test_decide_registry_ts_lock.py`（重跑生成器与磁盘逐字节比较，漂移即失败）；TS `dp3-answer.test.ts`/`dp2-narrow.test.ts` 各 1-2 例（snippets 原文出现、超 200 字符被裁、`assertStateMatchesRegistry` 在缺字段时 throw）。
